# 〈书名〉阅读笔记

## 复制说明

将本模板复制到 `books/<slug>/README.md`，再填写实际书目信息。内容较多时，可在 `books/<slug>/chapters/` 下分章记录。本节可在建立笔记后删除。

模板不预置导航链接，避免复制后指向错误。若笔记放在上述书籍总览位置，返回书籍专区的相对路径为 `../README.md`，返回仓库首页为 `../../README.md`，文件格式指南为 `../../docs/file-formats.md`。从 `chapters/` 内链接到本书总览使用 `../README.md`；返回书籍专区使用 `../../README.md`。确认目标文件存在后，再把所需路径写成 Markdown 链接。
