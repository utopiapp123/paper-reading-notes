# 书籍阅读专区

这里按书籍和章节整理阅读目标、概念、公式推导、问题与个人心得。具体书目和阅读进度由实际阅读记录补充。

## 书目

新增书籍时，在此登记书名、版本、阅读状态和对应笔记入口。

## 建议组织方式

每本书建立一个目录，用总览记录全书目标、章节顺序和进度；内容较多时，在 `chapters/` 下分章记录。

```text
books/
  README.md
  <slug>/
    README.md
    chapters/
      01-<chapter-slug>.md
      02-<chapter-slug>.md
    assets/
```

以上路径是结构示例，建立实际文件后再添加目录链接。`<slug>` 使用简短、稳定的书名缩写，章节文件名带序号，便于排序。

## 开始一本书

1. 复制书籍笔记模板到 `books/<slug>/README.md`。
2. 填写书名、作者、版次及来源链接，再根据自己的目标安排章节顺序。
3. 记录章节进度时以实际阅读情况为准；摘录、书中结论、自己的复述和判断分别写清楚。
4. 分章后，在书籍总览中添加真实存在的章节链接，并在本页增加书目入口。

正文优先使用 Markdown，方便 GitHub 直接预览、维护目录和显示数学公式。需要固定分页或用于打印时，可另外生成 PDF；不同格式的取舍见文件格式指南。
